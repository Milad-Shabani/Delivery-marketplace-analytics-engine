# Dashboard Guide

`dashboard/index.html` is a single self-contained HTML page (Plotly.js loaded
from jsDelivr; no build step, no server, works via `file://`). It reads its
data from `dashboard/data/novafood_data.js`, a plain `window.NOVAFOOD_DATA`
JS object generated by `scripts/build_dashboard_data.py` — this avoids
fetch()/CORS issues when opening the file directly from disk, and avoids
parsing the .xlsx client-side.

## Regenerating the dashboard data

```bash
python scripts/run_pipeline.py          # regenerates data/raw + data/processed
python scripts/build_dashboard_data.py  # refreshes dashboard/data/novafood_data.js
```

Then just open `dashboard/index.html` in a browser (or re-publish to GitHub
Pages — see the README "How to run" section).

## Sections

| Section | What it answers |
|---|---|
| Executive Overview | Are we growing profitably? Trailing KPIs, GMV/orders trend, city profit ranking |
| Financial | Revenue mix, cost structure, contribution-margin trend, driver decomposition |
| Customers & Retention | Segment mix, LTV:CAC by channel, cohort retention heatmap |
| Restaurants | Revenue-vs-margin quadrant (Star / Volume Trap / Niche Profit / Review) |
| Operations | On-time delivery and cancellation rate trends |
| Forecast & Planning | 12-month forecast with interval, model-selection table, strategic plan verdict |
| Scenario & Optimization | Base/Upside/Downside contribution-profit scenarios, promo-budget optimization |

## Updating design tokens

Colors and spacing are defined once as CSS custom properties near the top of
`dashboard/index.html` (`:root { --navy: ...; --teal: ...; }`) — change them
there rather than per-chart.
